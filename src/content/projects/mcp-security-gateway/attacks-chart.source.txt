attacks-chart.svg (English), attacks-chart.ja.svg and attacks-chart.id.svg: a
chart drawn for this site from mcp-security-gateway's published results. It adds
no data of its own.

Data: eval/results/gullible/summary.json and its README, on main in
https://github.com/NabilRobert/mcp-security-gateway (commit 414c755). The
scripted test agent ran the 12-task attack suite through the gateway in three
configurations; a square is filled when that task's attack took effect:

  gateway-off (screening off)              12/12  XXXXXXXXXXXX
  policy-only (read-only tools, no screen)  9/12  X.XX.XXXXXX.
  gateway-on  (rules + model at 0.999)      5/12  ..X..XX.X.X.

gateway-on matched the prediction committed before the run (prediction.json,
commit 5f3e3d2).

Drawn with Vega-Lite by charts/attacks-chart.ts in this repository, which holds
the data above and the labels in all three languages; `npm run charts`
redraws the SVGs and a test fails if they fall out of step with it. The
-narrow files are the same chart drawn 360 px wide, for phones.
